# 원국 상세 특징 계산 구현·검증

2026-10-19, 실행순서 15단계 완료 기록. 특징 버전 `1.0.0`, 고정표 버전 `1.0.0`이다. [확정 설계](./NATAL_DETAIL_SPEC.md)의 특징 계산 부분을 구현했다. 실제 해석 원고·선택 모듈·화면 연결은 16~17단계에서 진행한다.

## 구현

| 파일 | 역할 |
| --- | --- |
| `js/content/natal-tables.js` | 12지지 지장간 28항목, 본기/중기/여기 표시 순서, 12월지의 계절·시작 절기, 버전·출처. 상수와 중첩 배열/객체 동결 |
| `js/natal-features.js` | 순수 `calculateNatalFeatures(result)`, 기존 `describePillar`·`tenGodForStems` 재사용 |
| `tests/natal-features.test.mjs` | 기준표·100 천간 관계·280 지장간 관계·60일주·부분 사주·오류·재현성 검사 |

기존 사주 계산과 반환 계약, 입력 UI, 기존 해석 모듈에는 변경을 가하지 않았다. 새 모듈은 `calculateSaju()` 결과를 소비하며 DOM·저장·현재 시계·콘텐츠 문구에 의존하지 않는다. 입력을 다시 계산하거나 미확정 후보를 정상 기둥으로 채우지 않는다.

반환값:

- `version`, `policy`(기존 시간 정책 + 고정표 버전/ID), `status`, `partial`, `excludedPillars`, `uncertainty`.
- `dayMaster`·`dayPillar`: 확정 일간 메타데이터와 일주 전체 설명 객체. 일주는 60갑자의 유효 조합만 허용한다.
- `pillars`: 연·월·일·시 순. 확정 기둥에는 원래 간지·한글/한자·오행, `stemRelation`, `hiddenStems`를 담는다. 미확정 기둥은 null이다.
- 일간 위치의 `stemRelation`은 `{kind:'self',tenGod:null}`. 다른 위치의 같은 천간은 비견이다. 지장간도 일간에 대한 십성을 계산한다.
- 지장간의 `stem`, `role`, `order`(1부터), `tenGod`, `tableId`는 각 기둥에 보존한다. 동일 천간의 반복 위치를 합치거나 오행 수에 가산하지 않는다.
- `surfaceElements`: `{counts,total,kind:'surface-characters'}`. 원래 확정 천간·지지 집계와 일치하는지 검증한다.
- `season`: `{key,monthBranch,monthElement,termName}`. `monthBranch`는 한글·한자·오행 객체다. 확정 월주가 없으면 null이다.
- `context`: `{tenGod,source,pillarKey,stem}`. 월간 십성을 우선하고 월주가 없으면 일지 본기의 십성을 사용한다. 우세·강약 순위가 아니다.
- `availability`: 일간·일주·위치별 기둥·표면 오행·계절·맥락·5개 분야별 `{status,reason,partial,requiredFeatures}`. 부족한 특징과 그 때문에 제외한 영역을 구별한다. 실제 문구 누락 판단은 16단계에서 수행한다.

## 검증 및 오류 상태

입력 없음은 null이다. 잘못된 결과 구조, 60갑자에 없는 기둥, 간지와 한글/오행 불일치, 일간 불일치, 표면 집계 불일치, 미지원 시간 정책, 잘못된 양력 날짜, 시간 미상인데 시주가 있는 결과, 미확정 기둥과 후보 정보 불일치는 `RangeError`다. 미래 출생 금지와 달력 변환은 기존 `calculateSaju()`에서 검증하며 파생 모듈은 현재 시각을 읽지 않는다.

시간 미상은 시주와 파생 목록을 제외한다. 입춘 경계에서 연·월주가 미확정이면 두 기둥의 십성·지장간·계절을 제외하되, 일간/일주에 근거한 분야 해석을 위한 특징은 제공한다. 후보는 `uncertainty` 안내에만 복사한다. 연주만 없는 경우 확정 월주 계절은 유지한다.

설계의 방어적 미제공 상태를 다음처럼 구체화했다. 정상 `calculateSaju()`는 일간과 일주를 항상 제공하므로 아래는 후속 모듈의 오류 처리 검사용이다.

- `pillars.day=null`이고 `features.dayMaster=null`: `unavailable-day-pillar`, 상세 분야·맥락 미제공.
- 유효한 일주가 있어도 `features.dayMaster=null`로 명시된 경우: `unavailable-day-master`. 일간을 임의 복원하지 않고 관계·지장간 십성은 null로 둔다.
- 일간이 명시적으로 미확정이면 확정 기둥의 간지·지장간 목록 및 독립적인 표면 오행/월지 계절 사실은 남긴다. 일간이 필요한 상세 해석 영역은 `unavailable-feature`다. `stemRelation`은 null이며 실제 계산된 비견으로 위장하지 않는다.
- `features.dayMaster` 누락 또는 일주의 천간과 다른 값은 손상된 구조로 거부한다. `partial`은 기둥 제외 또는 일간 미확정 여부를 나타내고 `excludedPillars`는 실제 null 기둥만 나열한다.

객체·배열·메타데이터는 반환 시 복사한다. 한 호출의 결과를 수정해도 입력·다른 호출·고정표를 변경하지 않는다. 이름·입력 달력·조회 연도·날짜·개인정보는 원국 특징 반환에 넣지 않는다.

천간·지장간 조합의 단위 검사에는 계산 결과 형태로 만든 합성 fixture를 사용한다. 이를 실제 출생 원국이라고 주장하지 않는다. 실제 60일 출생·음력 등가·절입 경계 검사는 별도로 수행했다.

## 제한

지장간·십성표 비교는 채택한 동일 엔진 원본과의 일관성 검사다. 외부 독립 참고표 및 명칭·관행 차이 대조는 18단계에서 진행한다. 신강약·용신·가중치·지지 합충·사령·사건 예측은 계산하지 않는다. 원국 해석 콘텐츠·선택 모듈·화면 연결 및 브라우저 검수는 16~18단계의 후속 작업이다. 새 모듈은 아직 화면에서 호출하지 않으므로 이번 단계에서는 브라우저 화면 검사를 새로 수행하지 않았다.
