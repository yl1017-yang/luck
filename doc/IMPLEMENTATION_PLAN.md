# 운세 사이트 실행순서

이 문서는 [GUIDE.md](./GUIDE.md)의 개발 방향을 실제 작업 순서로 정리한 체크리스트다. 앞으로 아래 순서대로 진행하고, 완료한 항목만 체크한다.

## 개발 범위

- 1차: 오늘의 운세·사주팔자·내 성향
- 이후: 콘텐츠 보강과 평생운세 확장
- 구현 방식: 자체 계산 + 저장된 해석 문구
- 운영 중 외부 운세 API와 AI API 호출 없이 결과를 제공한다.

## 2. 입력 항목과 계산 기준 확정

- [x] 이름 또는 별명을 선택 입력(최대 20자)으로 추가하고 결과 제목·임시 저장·페이지 간 복원에 연결한다. 계산에는 사용하지 않는다.

- [x] 생년월일, 양력·음력, 음력 윤달 여부, 출생 시간을 공통 입력으로 정한다.
- [x] 출생 시간에 ‘시간 모름’ 옵션을 둔다.
- [x] 지원할 생년월일 범위를 정한다.
- [x] 출생지·시간대 지원 범위를 정하고 화면에 안내할 기준을 마련한다.
- [x] 절기, 날짜 경계, 출생 시간 미상 처리 기준을 문서화한다.
- [x] 오늘의 운세 날짜가 바뀌는 시간대와 갱신 기준을 정한다.
- [x] 입력 정보의 저장 여부와 저장 위치를 정한다.

완료 조건: 같은 입력을 어떤 기준으로 계산하는지 명확하며, 라이브러리 선정에 필요한 요구사항이 정리되어 있다.

2026-10-15: 2단계 기준 확정. 상세 내용은 [CALCULATION_POLICY.md](./CALCULATION_POLICY.md)를 따른다. 한국 출생·고정 UTC+9, 양력 환산 기준 1900년부터 오늘까지, 입춘·절입 및 00:00 일주 경계, 시간 미상 처리, 자정 날짜 키, sessionStorage 보관 정책을 정했다. 음력의 실제 유효성 및 환산 범위 검증과 사주 계산은 3단계 이후 구현한다.

## 5. 해석 콘텐츠와 연결 규칙 준비

- [x] 문구를 코드와 분리해 수정 가능한 데이터로 저장한다.
- [x] 사주팔자: 각 기둥, 일간, 오행 등 표시할 용어의 설명을 작성한다.
- [x] 내 성향: 행동 방식, 강점, 관계 방식, 스트레스 경향, 균형을 잡는 팁을 작성한다.
- [x] 오늘의 운세: 오늘의 흐름, 관계, 일·공부, 생활 조언, 주의점, 실천 팁을 작성한다.
- [x] 계산된 특징과 문구를 연결하는 조건을 정의한다.
- [x] 오늘 날짜를 반영하는 운세 선택 규칙을 정의한다.
- [x] 문구의 우선순위와 상충하는 문구의 제외 조건을 정한다.
- [x] 같은 입력과 같은 날짜에 같은 결과를 제공하도록 구성한다.
- [x] 단정적인 예측, 불안을 유발하는 표현, 중대한 의사결정을 유도하는 문구를 검토한다.

완료 조건: 지원하는 입력에 필요한 기본 해석이 제공되고, 내용이 모순되거나 빈 영역으로 남지 않는다. 콘텐츠용 해석 규칙과 만세력 계산은 구분해 관리한다.

2026-10-15 완료: 일간 10종의 성향 5영역·주제 8종·실천 24종·개인별 일간/오행 구성 설명을 데이터로 분리하고 세 메뉴에 연결했다. 같은 양력 환산 출생일·일주·날짜·콘텐츠 버전에서 결과가 재현되며, 이름·입력 달력 형식에 따른 운세 차이는 없다. 주제 하나에서 모든 조언을 고르는 우선순위로 상충 문구 혼합을 막았다. 세부 선택 규칙과 반복 범위는 [INTERPRETATION_RULES.md](./INTERPRETATION_RULES.md)를 따른다. 오늘의 운세는 길흉 예측이 아닌 날짜별 생활 제안이며, 성향은 일간 이미지 기반 자기 성찰용 초안이다.

### 현재 구현 상태와 다음 작업

생년월일 UI 개선: 세 페이지에서 직접 입력 대신 공통 연·월·일 선택을 사용한다. 양력 윤년·음력 일수·윤달·미래 날짜에 맞춰 선택지를 구성하고 기존 저장 데이터 형식과 복원을 유지한다.

공통 UI 클래스 정리 완료: 버튼 색상·아이콘·전체 너비, 배지, 입력창, 카드 배경, 대시보드 그리드를 공통화하고 세 HTML과 동적 배지 출력에 반영했다.

메뉴별 HTML, 공통 CSS, 입력·계산·해석 모듈과 별도 콘텐츠 데이터로 구성한다. 두 무료 달력 라이브러리는 로컬 배포 파일로 포함하며 npm 설치나 빌드는 없다. 로컬 실행 방법은 README.md에 기록했다.

세 메뉴 모두 실제 입력·사주 계산·저장된 해석 문구에 연결되어 있다. 오행은 확정된 기둥의 글자 수를 표시하며, 입력 전에는 가상의 개인별 결과를 표시하지 않는다. 출생 정보는 같은 탭에서 임시 유지되고 실천 체크는 입력·날짜·팁이 바뀌거나 페이지 이동·새로고침 시 초기화된다.

1~8단계의 정한 범위 구현과 검증을 완료했다. 평생운세는 인생 전반·연도별 세운 범위이며 대운은 향후 별도 확장이다. 과거 절기 전체의 독립 자료 대조·전문가 해석 감수·실제 모바일 기기 전체 검수·배포는 완료된 것으로 간주하지 않는다.

2026-10-15 검증: 날짜·윤달·양력 환산, 사주 표본·경계, 시간 미상, 콘텐츠 누락·재현성·반복 범위·문구 기준, 한국 날짜 전환과 브라우저 입력·메뉴 이동·복원을 확인했다. 상세 근거는 CALENDAR_VALIDATION.md, SAJU_VALIDATION.md, INTERPRETATION_RULES.md와 테스트 파일을 참고한다.

메뉴별 HTML 분리 완료: `index.html`, `saju.html`, `personality.html`. 공통 입력은 `js/common.js`, 메뉴별 출력은 `js/today.js`, `js/saju.js`, `js/personality.js`로 분리했다. 출생 정보는 sessionStorage로 같은 탭에서 유지되고 실천 체크는 페이지 이동·새로고침 시 초기화된다.
