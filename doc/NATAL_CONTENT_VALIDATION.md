# 원국 상세 콘텐츠·해석 선택 구현 및 검수

완료일: 2026-10-19. 원국 콘텐츠 버전 `1.0.0`. 실행순서 16단계 완료 기록이다. [14단계 설계](./NATAL_DETAIL_SPEC.md)와 [15단계 특징 계산](./NATAL_FEATURES_VALIDATION.md)을 기준으로 구현했다. 화면 연결과 종합 검증은 17~18단계다.

## 작성 범위와 재사용

| 파일 | 역할·분량 |
| --- | --- |
| `js/content/natal-entry.js` | 공통 스키마·버전 부착. 문구를 자동 생성하거나 유형을 추측하는 역할은 아님 |
| `js/content/natal-day-pillars.js` | 60일주별 개별 원고. 요약·2문단·생활 예시·질문·실천 |
| `js/content/natal-areas.js` | 일간 10종×5영역의 기본 원고 50개. 서로 다른 본문 100문단과 분야별 생활 예시 |
| `js/content/natal-contexts.js` | 십성 10종×5영역의 맥락 원고 50개. 조건과 점검 질문, 추가 실천 행동 없음 |
| `js/content/natal-details.js` | 기존 일간 설명 10개 재사용, 십성 주제 10개·계절 4개·월지 12개와 전체 카탈로그 |
| `js/natal-interpreter.js` | 특징 검증, 정확한 조건 선택, 조합·누락·부분 결과·근거 반환 |
| `tests/natal-interpreter.test.mjs` | 전체 카탈로그·60일주·400조합·근거·누락·재현성·문구 검사 |
| `tests/preview-natal.mjs` | 실제 출생일 테스트 표본 4건의 대표 출력 재생성 |

총 **196개 콘텐츠 ID**다. 이 중 일간 10개는 기존 `DAY_MASTERS`의 intro·behavior·strength·balance를 명시적으로 재사용하고 점검 질문을 덧붙였다. `sourceRefs`와 `sourceVersion`에 기존 콘텐츠의 필드·버전을 남긴다. 재사용한 10개를 새로운 독립 원고라고 세지 않는다. 나머지 186개를 작성했다. 원국 문구를 바꾸거나 재사용 원문의 변경을 반영하면 원국 콘텐츠 버전도 올려야 한다.

일주 60개의 상세 본문은 각각 작성했으며 이름만 바꾼 공통 문장 조합이 아니다. 120문단에 완전히 동일한 문자열 중복이 없다. 분야별 기본 50개도 100문단이 서로 다르다. 형식과 말투의 유사성은 남아 있고, 같은 D/P/C가 다시 사용되면 같은 문구가 반복되는 것은 의도된 동작이다.

## 선택과 반환 계약

```javascript
const features = calculateNatalFeatures(result);
const reading = interpretNatalDetails(features);
```

두 번째 인자 `catalog`는 편집 미리보기·누락 테스트용이다. `version`, `dayMasters`, `dayPillars`, `tenGods`, `seasons`, `monthBranches`, `areas`, `contexts`를 가진다. 앱 코드·현재 날짜·난수·DOM·sessionStorage에 의존하지 않는다.

반환은 `version`, `featureVersion`, `status`, `contentStatus`, `partial`, `note`, `facts`, `sections`, `contentIds`다. `facts`는 검증한 특징의 복사본이고 사용자 이름·원래 입력 달력은 포함하지 않는다.

출력 순서는 원국 요약 → 일간 → 일주 → 연/월/일/시 사실 → 실제 등장한 십성 주제 → 계절/월지 → 표면 오행 → 성향·일/자원·관계·생활 균형이다. 5개 분야 중 overview를 앞에서 먼저 출력하므로 뒤에서 중복하지 않는다.

- `sections[]`: `{key,title,summary,status,reason,basis,blocks,contentIds,missingContentIds}`. 미제공/부분 원고에는 message도 포함한다.
- 각 `blocks[]`는 선택된 원고의 ID·조건·버전·역할(`base`, `context`, `season`, `fact`)·본문·질문·실천을 보존한다. 역할이 맞지 않거나 기본 행동이 없는 원고는 미제공 처리한다.
- 일간은 D 키, 일주는 P 키, 분야 기본은 D/area 키, 분야 맥락은 C/area 키를 정확히 사용한다. requires에 무관한 조건이 추가되어도 일치로 취급하지 않는다.
- 기본 문구 → 맥락 순으로 고정한다. 맥락은 `action=null`이며 추가 행동을 지시하지 않는다. 계절 배경은 전역 계절 영역에서 한 번 표시하여 5개 분야마다 반복하지 않는다.
- 일주와 분야 근거에는 D/P, 실제 일지 본기·십성, 분야 맥락의 실제 비교 천간·위치·선택 사유를 남긴다.
- 십성 주제는 고정된 10종 순서 중 실제 존재하는 유형만 출력한다. 동일 유형은 한 번 설명하고 천간/지장간의 모든 등장 위치·역할·표 ID를 연결한다. 일간 자체의 self는 비견 등장 횟수에 넣지 않는다.
- 기둥별 사실과 표면 오행은 문구를 추가 생성하지 않고 해당 section의 basis/summary와 facts로 전달한다. 표면 오행 0을 완전한 부재·질환·성격 결핍으로 읽지 않는 안내를 포함한다.

## 예외·부분 결과

입력 null은 null이다. 잘못된 특징 버전·정책·일주·메타데이터·오행 집계·십성·지장간 순서/역할·계절·맥락·불확실성·해석 가능 상태는 `RangeError`로 거부한다. 특징의 가용 상태만 바꾸어 미확정 기둥을 해석에 포함할 수 없다.

일간/일주 미확정이면 기존 status와 facts만 반환하고 `contentStatus='unavailable'`, `sections=[]`로 상세 해석을 만들지 않는다.

시간 미상·출생 절입 경계에서는 해당 기둥을 `unavailable-feature`로 표시하고 후보의 십성·지장간은 사용하지 않는다. 월주 미확정 시 계절도 미제공하고 C는 15단계가 결정한 `day-branch-main`을 따른다. 사용할 수 있는 특징의 문구가 모두 있으면 부분 사주여도 `contentStatus='complete'`일 수 있다. 이 값은 사주 전체의 확정 여부가 아니라 필요한 원고의 충족 여부다.

기본 원고가 없거나 ID·조건·버전·필수 필드가 맞지 않으면 해당 영역은 `unavailable-content`, blocks는 빈 배열이다. 보조 원고만 누락되면 기본 원고는 남기고 `partial-content`로 표시한다. 다른 일간/일주/십성으로 대체하지 않는다. 십성 설명이나 일주 원고가 없어도 계산된 근거는 남긴다. 전체 원고 충족 상태는 `contentStatus='partial'`이다.

원본 카탈로그·계산 결과·호출 사이의 객체를 공유하지 않는다. 반환된 본문이나 사실을 수정해도 다음 호출은 영향을 받지 않는다.

## 실제 출력 편집 검수

[대표 출력 4건](./NATAL_CONTENT_SAMPLES.md)의 일주·원국 요약·성향·일/자원·관계·생활 균형을 읽고 비교했다.

| 표본 | 확인한 차이와 일관성 |
| --- | --- |
| 2000-01-07 12:00, 甲子 | 일지 癸=정인의 배움 관점과 월간 丁=상관의 표현/개선 맥락을 서로 다른 근거로 표시 |
| 2000-02-06 12:00, 甲午 | 같은 甲 기본 문구는 유지, 일지 丁=상관의 개선 질문과 월간 戊=편재의 자원 조건으로 다른 설명 선택 |
| 2024-02-04 시간 미상, 戊戌 | 연/월/시·계절 제외. 일지 본기 戊=비견을 맥락으로 사용하고 공동 기준과 지원·휴식 제안을 함께 유지 |
| 음력 2025 윤6월1일 12:00, 乙未 | 양력 7월25일과 등가. 일지 己=편재와 월간 癸=편인의 탐색 맥락을 구분. 유연함과 내 기준을 함께 다룸 |

편집 과정에서 일지 본기의 실제 십성과 다른 주제로 읽힐 수 있는 표현을 점검해 고쳤다. 예를 들어 甲午의 본기 丁은 상관이므로 개선 질문으로, 丁丑의 본기 己는 식신이므로 꾸준한 표현으로 정리했다. 실제 근거 출력과 편집 문장의 방향을 함께 확인했다.

기본 문구와 보조 문구가 같은 방향을 다른 관점에서 설명하는 반복은 허용한다. 일간 설명 10개는 기존 성향의 핵심 내용과 의도적으로 겹치므로 17단계 화면에서 공통 용어·기존 카드와의 중복 배치를 조정해야 한다. 단순히 분량을 늘려 전문 종합 풀이처럼 표현하지 않는다.

## 남은 범위

이번 단계에서는 화면을 변경하거나 브라우저 검수를 새로 수행하지 않았다. 상세 화면 연결은 17단계, 독립 지장간 참고표 대조·전체 검증·문서 마무리는 18단계다. 신강약·용신·대운·합충·성별/혼인/직업 가정·사건 예측은 포함하지 않는다. 문구는 편집한 자기 성찰용 설명이며 전문 사주 감수나 예측 타당성 검증을 완료한 것이 아니다.
