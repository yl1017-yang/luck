# 평생운세 제공 범위와 계산 기준

구현일: 2026-10-15. 콘텐츠 버전 1.0.0.

## 이번 확장의 범위

- 상단 네 번째 메뉴와 별도 `lifetime.html` 페이지를 제공한다.
- 기존 공통 입력·이름·한국 음력 변환·사주 계산·임시 저장을 재사용한다. 추가 성별 입력은 받지 않는다.
- 인생 전반의 경향은 일간 10종과 일간의 오행 5종 콘텐츠를 연결한다.
- 강점, 일·배움, 관계, 시간·자원 관리, 전환점, 생활 습관의 여섯 영역을 제공한다.
- 시기별 흐름은 **연도별 세운**을 제공한다. 현재 입춘 구간부터 최대 다섯 구간이며 2050년까지만 표시한다.
- **대운은 이번 범위에 포함하지 않는다.** 대운 시작 나이·순행/역행을 임의로 추정하지 않는다. 추후 도입 시 적용할 성별·연간 음양의 순역 규칙, 절입 거리와 시작 나이 환산 방식을 따로 정하고 필요한 입력을 추가한다.

이 범위의 평생운세는 일생의 사건을 미리 확정하는 기능이 아니다. 수명, 결혼 시기, 특정 나이의 성공·손실을 예측하지 않는다.

## 연도별 세운

1. `annualPillar(year)`는 고정 버전 엔진의 해당 연도 간지와 입춘 구간을 반환한다.
2. 입춘 시각은 엔진의 UTC+8 시각을 실제 순간으로 해석하고 고정 UTC+9 표시로 변환한다.
3. 한 구간은 해당 연도 입춘부터 다음 연도 입춘 직전까지다. 양력 1월 1일이나 음력 설에 바뀌지 않는다.
4. 조회 시각이 올해 입춘 전이면 전년도 구간을 첫 카드로 보여준다. 입춘 이후에는 올해 구간부터 보여준다.
5. 조회가 입춘 ±60초 이내면 현재 구간 표시를 확정하지 않고 경계 안내를 표시한다. 이 유예는 전체 과거 절기의 오차 상한을 뜻하지 않는다.
6. 공통 시계 이벤트를 1분 간격과 탭 복귀 때 받아 입춘 당일에도 구간을 다시 판단한다. 날짜만 바뀔 때까지 기다리지 않는다. 입력·구간·경계 상태가 같으면 DOM을 다시 만들지 않는다.
7. 연도 조회는 1901~2050년을 지원한다. 2050년 카드의 종료 입춘 표시만 2051년 계산을 사용한다. 범위 끝에서는 다섯 카드보다 적을 수 있다.

## 십성과 해석

연도 천간과 출생 일간의 오행 관계·음양을 비교해 천간 십성을 계산한다. 지지 간지 자체는 표시하지만 지지의 합충·형파해·지장간과 대운의 상호작용은 이번 해석에 넣지 않는다.

| 관계 | 음양 같음 | 음양 다름 |
| --- | --- | --- |
| 같은 오행 | 비견 | 겁재 |
| 일간이 생하는 오행 | 식신 | 상관 |
| 일간이 극하는 오행 | 편재 | 정재 |
| 일간을 극하는 오행 | 편관 | 정관 |
| 일간을 생하는 오행 | 편인 | 정인 |

계산한 십성 이름과 간지·구간은 계산 데이터다. 여기에 연결하는 생활 주제는 별도의 편집 콘텐츠다. 재성은 재물 획득, 관성은 위험이나 성공 등으로 단정하지 않는다. 자원 관리·역할 확인·배움·표현·협력의 관점으로 읽도록 작성했다.

## 시간 미상과 불확실성

- 인생 경향과 연도 천간 십성은 확정된 일간을 사용하므로 시간 미상에도 제공할 수 있다.
- 출생 시주나 절입 경계의 연·월주를 임의로 보완하지 않는다. 부분 사주라는 안내를 유지한다.
- 이름이나 입력한 달력 형식은 해석을 바꾸지 않는다. 같은 양력 환산 출생일·일간은 같은 결과를 제공한다.
- 입력 전에는 개인별 경향·연도 카드를 표시하지 않는다. 지원 범위 밖의 조회는 무관한 기본 결과 대신 안내한다.

## 파일

- `js/content/lifetime.js`: 오행별 인생 경향과 십성 10종의 연도별 해석
- `js/lifetime-interpreter.js`: 공통 계산 결과와 조회 시각을 받아 해석·구간 선택
- `js/saju-calculator.js`: 입춘, 연도 간지, 천간 십성 계산
- `js/lifetime.js`: 결과 표시와 공통 입력·시계 이벤트 구독
- `lifetime.html`: 독립 페이지. 공통 스타일·카드·입력창 재사용

## 검증과 출처

`tests/lifetime.test.mjs`에서 다음 일곱 묶음을 확인했다.

- 2026~2030년 간지 순서와 연도 구간 연속성
- KASI 2024·2026년 입춘 분 단위 참고 시각과 60초 이내 비교
- 천간 조합 100개의 십성을 원본 엔진의 SHI_SHEN 표와 비교
- 1월 1일의 이전 구간 유지, 입춘 직전·정각·직후 전환과 경계 안내
- 일간 10종의 인생 여섯 영역 누락 여부
- 음력 윤달과 양력 등가 입력, 시간 미상, 저장 데이터 복원 일관성
- 입력 없음·조회 오류·2050년 상한과 카드 수 제한
