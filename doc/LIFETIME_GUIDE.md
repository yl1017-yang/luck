## 분야별 상세·월운 후속 설계

- 기존 인생 경향과 최대 다섯 세운 요약 카드를 유지하고, 그 아래 `annual-detail` 영역에 연도 선택·적용 세운 탭·총론·네 분야·월운을 추가한다. 사주팔자는 이 영역으로 링크한다.
- 연도 선택은 양력 기준 `max(1901, 양력 환산 출생연도)`~2050이다. 기본은 한국 현재 연도이며 범위 밖이면 안내한다. 기존 요약 카드의 세운 연도와 새 상세의 양력 연도를 구분한다.
- 입춘 전/후 두 세운을 기간별 탭으로 제공한다. 현재 연도 최초 조회는 현재 세운, 다른 연도는 해당 연도 세운을 기본으로 한다. 입춘 ±60초에는 자동 확정을 유예한다.
- 12개월 월운은 양력 월별로 묶고 절입 전후 구간을 각각 표시한다. 연간 탭을 바꿔도 월운의 연간 십성은 각 구간의 실제 세운을 따른다. 출생 전 월은 문구 없이 상태만 표시한다.
- 연도 카드의 상세 링크는 카드의 세운 탭을 연다. 상세 범위 밖인 1900 세운 요약은 기존대로 표시하되 상세 링크는 제공하지 않는다.
- 선택값은 별도 sessionStorage 키에 저장하고 입력 변경 후 유효성을 다시 확인한다. 사용자가 고른 기간은 시계 갱신으로 덮어쓰지 않으며 현재 강조·경계 안내만 갱신한다.
- 초기 해석은 확정된 일간 대비 연도·월간 천간 십성만 사용한다. 시간 미상에도 제공 가능하며 지지 합충·대운·신강약·용신·성별 추가 입력은 포함하지 않는다.
- 계산 모듈 `js/fortune-periods.js`, 해석 모듈 `js/fortune-interpreter.js`, 콘텐츠 `js/content/annual-details.js`·`monthly-details.js`를 구현했다. `js/fortune-view.js`에서 화면에 연결하며 선택·기간 표시 규칙은 `js/fortune-view-state.js`를 사용한다.

## 이번 확장의 범위

- 상단 네 번째 메뉴와 별도 `lifetime.html` 페이지를 제공한다.
- 기존 공통 입력·이름·한국 음력 변환·사주 계산·임시 저장을 재사용한다. 추가 성별 입력은 받지 않는다.
- 인생 전반의 경향은 일간 10종과 일간의 오행 5종 콘텐츠를 연결한다.
- 강점, 일·배움, 관계, 시간·자원 관리, 전환점, 생활 습관의 여섯 영역을 제공한다.
- 시기별 흐름은 **연도별 세운**을 제공한다. 현재 입춘 구간과 그다음 구간의 2개 연도를 2050년까지만 표시한다.
- **대운은 이번 범위에 포함하지 않는다.** 대운 시작 나이·순행/역행을 임의로 추정하지 않는다. 추후 도입 시 적용할 성별·연간 음양의 순역 규칙, 절입 거리와 시작 나이 환산 방식을 따로 정하고 필요한 입력을 추가한다.

이 범위의 평생운세는 일생의 사건을 미리 확정하는 기능이 아니다. 수명, 결혼 시기, 특정 나이의 성공·손실을 예측하지 않는다.

## 연도별 세운

1. `annualPillar(year)`는 고정 버전 엔진의 해당 연도 간지와 입춘 구간을 반환한다.
2. 입춘 시각은 엔진의 UTC+8 시각을 실제 순간으로 해석하고 고정 UTC+9 표시로 변환한다.
3. 한 구간은 해당 연도 입춘부터 다음 연도 입춘 직전까지다. 양력 1월 1일이나 음력 설에 바뀌지 않는다.
4. 조회 시각이 올해 입춘 전이면 전년도 구간을 첫 카드로 보여준다. 입춘 이후에는 올해 구간부터 보여준다.
5. 조회가 입춘 ±60초 이내면 현재 구간 표시를 확정하지 않고 경계 안내를 표시한다. 이 유예는 전체 과거 절기의 오차 상한을 뜻하지 않는다.
6. 공통 시계 이벤트를 1분 간격과 탭 복귀 때 받아 입춘 당일에도 구간을 다시 판단한다. 날짜만 바뀔 때까지 기다리지 않는다. 입력·구간·경계 상태가 같으면 DOM을 다시 만들지 않는다.
7. 연도 조회는 1901~2050년을 지원한다. 2050년 카드의 종료 입춘 표시만 2051년 계산을 사용한다. 2050년 입춘 이후에는 지원 상한으로 해당 연도 1개만 표시한다.

## 십성과 해석

연도 천간과 출생 일간의 오행 관계·음양을 비교해 천간 십성을 계산한다. 지지 간지 자체는 표시하지만 지지의 합충·형파해·지장간과 대운의 상호작용은 이번 해석에 넣지 않는다.

| 관계 | 음양 같음 | 음양 다름 |
| --- | --- | --- |
| 같은 오행 | 비견 | 겁재 |
| 일간이 생하는 오행 | 식신 | 상관 |
| 일간이 극하는 오행 | 편재 | 정재 |
| 일간을 극하는 오행 | 편관 | 정관 |
| 일간을 생하는 오행 | 편인 | 정인 |

계산한 십성 이름과 간지·구간은 계산 데이터다. 여기에 연결하는 생활 주제는 별도의 편집 콘텐츠다. 재성은 재물 획득, 관성은 위험이나 성공 등으로 단정하지 않는다. 자원 관리·역할 확인·배움·표현·협력의 관점으로 읽도록 작성했다.

## 시간 미상과 불확실성

- 인생 경향과 연도 천간 십성은 확정된 일간을 사용하므로 시간 미상에도 제공할 수 있다.
- 출생 시주나 절입 경계의 연·월주를 임의로 보완하지 않는다. 부분 사주라는 안내를 유지한다.
- 이름이나 입력한 달력 형식은 해석을 바꾸지 않는다. 같은 양력 환산 출생일·일간은 같은 결과를 제공한다.
- 입력 전에는 개인별 경향·연도 카드를 표시하지 않는다. 지원 범위 밖의 조회는 무관한 기본 결과 대신 안내한다.

## 개인별 평생 풀이 보강 (2026-10-19)

평생운세 상단은 총평과 초년·중년·말년, 성격·직업·재물·관계·생활 균형의 8개 카드로 구성한다. `js/content/lifetime-narratives.js`의 별도 원고 버전 3.1.0을 `js/lifetime-narrative.js`에서 선택한다. 본문은 용어 정의 대신 일할 때의 행동, 반복되는 갈등, 비용을 쓰는 계기, 가까운 관계의 기대를 구체적인 장면으로 설명한다. 일간 10종별 6영역, 십성 10종별 7영역, 중년·생활 균형 각 10종, 사회생활/가까운 생활의 5×5 조합 25종을 작성했다. 간지·십성 용어는 근거 펼치기에 둔다. 긴 설명은 단일 열과 문단으로 표시한다.

초년은 연주 천간과 지지 본기, 중년은 일지 본기, 말년은 시주 천간과 지지 본기의 십성을 삶의 과정에 연결한 편집 관점이다. 대운·시작 나이·순역을 계산하지 않으므로 연령 구간이나 사건 시점을 붙이지 않는다. 미확정 기둥에 해당하는 초년·말년 풀이를 생성하지 않는다. 성격·직업·재물은 일간과 월간 십성, 관계·생활은 일간과 일지 본기 십성을 사용한다. 총평은 일간 기본 문구에 월간과 일지 본기의 십성군 조합(비겁/식상/재성/관성/인성)을 연결한다. 월주 미확정이면 이 비교는 생략하고 분야의 월간 맥락은 일지 본기로 대체했음을 근거에 밝힌다. 이름·조회 연도로 내용을 임의 변형하지 않으며 선택한 원고 ID와 버전을 반환한다. 같은 특징의 반복을 허용한다. 생년월일로 실제 성격·이력을 확인하거나 예측 타당성을 검증한 결과로 표현하지 않는다. 연간 세운·월운 계산은 기존 기준을 유지한다.

검증: 평생운세·개인 원고 모듈 14개 검사 통과. 60개 일주에서 본문 완전성·동일 문단 중복 방지, 일간 10종·십성 10종·25조합 원고 누락, 출생 시각 변경의 영향 범위, 같은 일주의 월간 변화, 시간 미상·월주 미확정·이름 독립성을 확인했다. 전체 모듈 실행은 101개 중 100개 통과, 기존 `historical-terms.test.mjs`의 `usno-1900.json` 체크섬 불일치 1건은 이번 수정과 별개로 남아 있다. 샌드박스에서 자식 프로세스 생성이 제한되어 전체 검사는 `node --test --experimental-test-isolation=none tests/*.test.mjs`로 실행했다.

Chrome 회귀 검증: `node tests/run-browser.mjs`의 기본 입력·메뉴 이동·복원·반응형, 연간/월간 상세, 원국 상세 3개 스크립트 모두 통과했다. 평생운세 8개 카드와 초년·중년·말년 제목, 카드별 근거 펼치기, 본문에 계산 용어를 나열하지 않는 것도 확인했다.

3.0.0의 본문은 “함께 살펴보세요”, “시작할 수 있어요” 같은 해설·권유 문체를 쓰지 않는다. `lifetime-profiles.js`에 일간별 인물 유형·강점·맞는 업무·피할 환경·재물·관계·생활 문구와 제목·태그를, `lifetime-direct-relations.js`에 십성별 직접 풀이를 둔다. `lifetime-narratives.js`는 이들을 내보내고 25개 조합 총평을 보관한다. “당신은 …하는 사람입니다”로 먼저 유형을 설명한 뒤 구체적인 능력과 약점을 연결한다. 직업은 실제 업무 예시와 환경 조건을 함께 말한다. 인물 유형 제목과 태그도 선택한 원고에서 가져온다. 직접적인 문체가 실제 성격·이력의 확인이나 예측의 정확성을 뜻하지는 않으며 공통 해석 안내와 근거는 유지한다. 본문의 용어 해설·권유 표현 재등장 방지와 실제 Chrome의 3.0.0 표시·직접 서술 문장을 검증했다.

화면 중복 정리(2026-10-19): 중간의 연간 총론·재물·직장/사업·가정/건강·대인관계 5개 상세 카드를 제거했다. 상단 개인 풀이 → 입춘 기준 연도별 요약 → 선택 연도의 12개월 월운으로 이어진다. 제거된 상세 카드만 바꾸던 별도 세운 선택도 제거했고, 연도별 버튼은 해당 연도의 월운으로 이동한다. 기존 연간/월간 계산과 저장 데이터 형식은 유지한다. Chrome 3개 회귀 스크립트에서 중복 영역 부재, 연도·월 선택/복원, 키보드·반응형·절입 경계 동작을 확인했다.

3.1.0 상세 분량 확장(2026-10-19): `lifetime-depth.js`에 일간별 총운·분야별 확장 문단 100개, `lifetime-stage-depth.js`에 십성별 초년·중년·말년 확장 문단 90개를 추가했다. 총운은 4문단(월주 미확정이면 3), 각 시기별 풀이 4~5문단, 성격·생활 균형 3문단, 직업·재물·관계 4문단을 본문에 바로 표시한다. 미확정 기둥의 시기별 설명은 기존과 같이 보류한다. 초년·말년은 해당 기둥 천간 십성의 심화 원고를 연결하고, 중년은 일지 본기 십성의 심화 원고를 연결한다. 같은 원고를 다른 카드에 복사해 분량을 늘리지 않는다. 각 확장 문단에 선택 ID를 두고 기존 원고 버전과 함께 반환한다.

## 월운 개인 서술형 본문 (2026-10-19)

월운은 재물·직장·가정·관계·주의점·실천 제안의 항목별 짧은 조언 대신 기간별 7개 문단을 연결한 개인 풀이로 표시한다. `js/content/monthly-narratives.js`의 월간 십성별 5문단 50개, 일간별 10문단, 연간 십성별 10문단을 `js/monthly-narrative.js`에서 선택한다. 월간 총평 → 일간에 따른 반응 방식 → 일·자원·관계·주의점 → 해당 세운의 맥락 순서로 이어진다. “살펴보세요”, “적어보세요” 같은 체크리스트 문체와 분야별 소제목·강조 박스를 본문에 출력하지 않는다.

기존 기간 계산과 연간/월간 원고 데이터는 유지하며, 상세 해석 결과의 각 제공 가능한 월운 구간에 `narrative`를 추가한다. 새로운 서술 원고 버전 1.0.0과 선택 ID·계산 근거는 별도로 관리한다. 계산된 일간 및 연·월 천간 십성의 일치를 확인하며 이름·접속 시각·난수로 문구를 변형하지 않는다. 절기 구간·출생 전·미제공·경계 후보 처리는 유지한다. 간지와 십성은 각 카드 아래 해석 기준으로, 공통 제한 안내는 월운 해석 안내 펼치기로 표시한다. 실제 사건·수입·진단 등을 확정하는 예측으로 사용하지 않는다.

관련 모듈 검사 17개 및 Chrome 3개 회귀 스크립트 통과. 월운 신규 검사는 원고 70문단 완전성·중복, 천간 1,000조합의 정확한 선택·7문단 구성·근거 보존, 사용자 예시의 계수/겁재 직접 서술과 잘못된 근거 거부를 확인했다. Chrome에서 항목 소제목 부재, 7문단의 직접 서술 표시, 연도·월 복원·편집·모바일·절입 경계를 확인했다.

## 연도별 흐름 2개 연도·개인 서술형 변경 (2026-10-19)

연도 카드는 현재 한국 표준시 입춘 구간과 바로 다음 구간만 표시한다. 입춘 전이면 전년도·올해, 입춘 이후면 올해·다음 해다. 2050년 상한과 입춘 ±60초 유예를 유지한다. `annual-narrative.js`가 `content/annual-narratives.js`의 십성별 연간 문단 40개와 일간별 연간 연결 문단 10개를 선택하여 연도별 5문단을 제공한다. 개인 성향·일·돈·관계를 문장으로 연결하며 실천 조언 박스는 표시하지 않는다. 간지·십성은 근거 펼치기에 표시한다. 연도별 원고 버전 1.0.0과 선택 ID를 별도로 보관한다. 이전 기록의 최대 5개 요약 카드 설계를 대체한다.

검증: 평생운세 관련 16개 검사와 Chrome 3개 스크립트 통과. 실제 일간/연간 관계 100조합의 선택·5문단·근거 일치, 원고 50문단 중복 방지, 입춘 전후 2개 연도와 2050년 상한, 카드 2개 실제 표시·월운 이동·반응형을 확인했다.
