# 한국 음력 변환 연결 기록

## 선정과 범위

2026-10-15, korean-lunar-calendar 0.4.0을 한국 음력 변환 도구로 선정했다.

- [공식 저장소](https://github.com/usingsky/korean_lunar_calendar_js): MIT, 브라우저 ESM 지원, 런타임 의존성 없음
- [패키지 정보](https://github.com/usingsky/korean_lunar_calendar_js/blob/main/package.json): 버전·배포 형식 확인
- [커밋 이력](https://github.com/usingsky/korean_lunar_calendar_js/commits/main/): 유지보수 참고. 향후 유지보수 지속 여부를 보장하지 않음
- 양력 지원 1000-02-13~2050-12-31, 음력 지원 1000-01-01~2050-11-18
- 서비스에서는 입력 연도 1900년부터, 양력 환산 후 오늘까지로 제한한다.
- MIT 고지, 다운로드 주소와 원본 해시는 vendor 폴더에 보관했다. 계산 시 외부 API·CDN 호출은 없다.

## 검증

명령: `node --experimental-default-type=module tests/calendar.test.mjs`

| 구분 | 확인 내용 |
| --- | --- |
| KASI 달력자료와 비교 | 양력 2024-02-10 = 음력 2024-01-01 |
| 공식 라이브러리 README 사례 | 2017-06-24 = 음력 윤5월 1일, 1956-03-03 = 음력 1월 21일 |
| 윤달 회귀 | 2025-07-25 = 음력 윤6월 1일, 없는 윤달·윤6월 30일 거부 |
| 범위 | 1900-01-01 허용, 1899년·2051년·미래일 거부 |
| 음력 미래일 | 음력 2026-10-01은 양력 2026-10-15보다 뒤이므로 거부 |
| 왕복 | 2025년 365일 전체 양력→음력→양력 일치 |
| 기존 기능 | 시간 미상 null, 이름 없는 저장 데이터, 한국 시간 자정 유지 |

[KASI 2024 달력자료](https://astro.kasi.re.kr/kor/life/post/calendarData?search_year=2024)는 공식 월력요항 발표 전 자료라는 자체 안내가 있다. 2017·1956 사례는 [라이브러리 문서](https://github.com/usingsky/korean_lunar_calendar_js)의 예제와 비교했다. 왕복 검사는 내부 일관성을 확인하며 모든 날짜의 독립적인 정확성 검증은 아니다.

5개 테스트 묶음 모두 통과했다. 세 페이지와 로컬 모듈 HTTP 응답도 별도로 확인한다. 브라우저에서 실제 입력·페이지 이동을 조작하는 검수는 미수행이다.

## 남은 작업

이 라이브러리의 간지 출력을 절입 시각 기준의 사주팔자로 간주하지 않는다. 절기 시각·입춘·자정·시주 계산과 시간 미상 경계 처리는 별도 엔진을 선정하고 검증해야 한다. 오늘의 운세·사주팔자·내 성향 결과는 계속 고정 예시다. 3단계 전체 완료가 아니다.
