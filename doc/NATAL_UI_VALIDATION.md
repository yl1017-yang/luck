# 사주팔자 상세 화면 연결 검수

2026-10-19, 실행순서 17단계 완료 기록. 15단계 특징 계산과 16단계 원고·해석 선택을 실제 `saju.html`에 연결했다. 18단계 독립 참고 자료 대조·종합 검증은 후속 작업이다.

## 화면과 동작

- 기존 네 기둥·한글 독음·출생 정보·연간 상세 링크를 유지한다. 새 상세는 원국 요약 → 일간·일주 → 기둥별 십성·지장간 → 계절·오행 → 나머지 4개 분야 순으로 보여준다. 첫 원국 요약을 포함해 분야는 5개다.
- `js/saju.js`에서 입력 구독·복원 시 `calculateNatalFeatures()` → `interpretNatalDetails()` → `renderNatalDetails()`를 실행한다. `js/natal-view.js`는 DOM 출력을 담당한다.
- 일간 기준·일주·일지 본기·분야별 실제 비교 천간·맥락 선택 사유·십성 등장 위치를 ‘계산 근거 보기’에서 확인한다. 한자에는 한글 표기를 함께 보여준다. 내부 콘텐츠 ID·원래 JSON은 화면 본문에 노출하지 않는다.
- 기둥별 간지·십성·지장간은 계산 사실로 표시하고, 같은 십성의 편집 설명은 등장 위치를 모아 한 번 제공한다. 일간 자체는 ‘일간·나의 기준’으로 구별한다. 지장간은 본기·중기·여기, 천간, 오행, 일간 대비 십성을 목록으로 표시한다.
- 표면 오행 수는 기존 정의대로 확정된 글자만 집계한다. 지장간과 합산하지 않으며 강약 점수나 결핍으로 단정하지 않는 안내를 유지한다.
- 예전 사주 카드 6개 중 일간·오행 요약은 상세로 옮기고, 공통 용어 4개는 마지막 ‘사주 기초 용어 알아보기’ 안에 둔다. 입력 전에도 공통 용어는 읽을 수 있다.
- 개인별 요약과 일주 상세는 기본으로 펼치고 나머지 긴 설명·근거는 네이티브 details/summary로 읽는다. 소제목·문단·생활 예시·점검 질문·실천을 구분하고 키보드 포커스를 표시한다.
- 상세 영역 이동은 상대 앵커 링크로 제공하며 제목을 포커스 대상으로 지정한다. 메뉴 4개와 페이지 분리를 유지한다. 이름 등 입력값은 기존 textContent 출력과 동일하게 안전하게 처리한다.
- 원국은 출생 때의 기본 경향, 연간 운세·월운은 선택 기간의 풀이임을 화면에 표시하고 기존 평생운세 링크를 유지한다.

## 예외·갱신

입력 전에는 개인별 상세를 만들지 않고 입력 안내를 표시한다. 시간 미상에서는 시주 설명을 제외한다. 출생 입춘 경계에서 연·월·시가 미확정이면 해당 사실·계절 설명을 제외하고 일지 본기를 사용하는 이유를 표시한다. 확인 가능한 나머지 상세는 제공한다.

일간·일주 미확정은 상세 미제공 안내, 계산 예외는 정보 수정 안내를 보여준다. 오류 시 이전 상세와 기둥을 지워 예전 결과가 정상 결과처럼 남지 않게 한다. 기본 원고 누락은 해당 영역 미제공, 보조 원고 누락은 기본 문구를 유지한 부분 제공으로 구별하고 계산 근거는 남긴다.

입력 수정·메뉴 복귀·새로고침은 기존 `luck.birthProfile.v1`을 기반으로 다시 계산한다. 상세 펼치기 상태는 현재 페이지 메모리에서만 유지한다. 시계 이벤트는 출생 원국 상세를 다시 그리지 않으므로 펼친 상태와 포커스를 바꾸지 않는다. 별도 서버 전송·URL 개인정보·localStorage 저장을 추가하지 않았다.

## 실행 결과

```powershell
node --test tests/*.test.mjs
node tests/run-browser.mjs
```

- 전체 모듈 **88개 통과, 실패 0개**.
- 기존 `browser-smoke.mjs` 통과. 사주 공통 카드 개수 검사는 6개에서 분리된 공통 용어 4개로 갱신하고 실제 상세 영역의 표시도 확인한다.
- 기존 `fortune-browser.mjs` 통과. 연간 상세·월운 선택·입력 수정·복원·시계 경계·모바일 회귀를 확인했다.

- `git diff --check`, 변경 JavaScript 문법, 문서 상대 링크·체크 상태를 확인했다.
