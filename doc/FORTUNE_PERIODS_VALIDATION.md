# 연간 상세·월운 기간 계산 구현 결과

구현·검증일: 2026-10-16. 실행순서 10단계 완료 기록이다. 해석 문구와 화면 연결은 11~12단계에서 진행한다.

## 구현

`js/fortune-periods.js`의 `calculateFortunePeriods(result, year, now)`는 검증된 `calculateSaju()` 결과와 선택 양력 연도, 조회 순간을 받는다. DOM·sessionStorage·콘텐츠 의존성이 없는 계산 모듈이다. 기존 `annualPillar()`·`tenGodForStems()`를 재사용하며 기둥 설명 형식은 기존 `describePillar()`를 export해 공유한다.

- 선택 범위: `max(1901, 양력 출생연도)`~2050. 출생 연도는 양력 출생일의 고정 UTC+9 00:00부터 표시한다.
- 반환: `year`, `range`, `dayMaster`, `partial`, `excludedPillars`, `annualPeriods`, `months`, `current`, `status`.
- 연간 구간은 입춘 기준 이전/해당 세운을 선택 연도·출생일 범위와 교차한다. 월운은 12절입 기준 월주·일간 대비 월간 십성을 구한 뒤 양력 월·연간 구간과 교차한다.
- `sourceStart/sourceEnd`는 원래 절기 구간, `start/end`는 표시 구간이다. 모두 ISO UTC 순간이며 시작 포함·끝 제외다. 화면에서는 UTC+9로 변환해야 한다.
- 정상 결과의 `months`는 항상 12개다. 출생 전 월은 `before-birth`, 정상 월은 `available`, 구간 누락/중복 검출 월은 `calculation-error`다.
- 입력 없음은 `null`. 잘못된 연도·조회 시각·양력 날짜는 `RangeError`. 일간 미확정은 `unavailable-day-master`로 빈 기간을 반환한다. 엔진 자체의 절기표 실패는 예외로 전달하므로 후속 화면이 계산 실패를 안내해야 한다.
- 미확정 기둥은 `excludedPillars`에 표시하고 일간이 확정되어 있으면 계산한다. 시간 미상의 시주나 출생 순간을 만들어 넣지 않는다.
- 조회 순간이 표시 범위 내의 절입 ±60초이면 `nearBoundary=true`, `activeSegmentId=null`이다. `candidateSegmentIds`에는 반환된 표시 구간 중 경계 양쪽 구간을 넣는다. 출생일로 한쪽이 제외된 경우에는 존재하는 후보만 반환한다. 선택 연도/출생일 범위 밖의 순간은 현재 구간을 표시하지 않는다.
- 동일 입력·연도·조회 순간에는 동일 결과를 반환하며, 호출 간 공유되는 변경 가능한 기둥 객체를 만들지 않는다.

시계 이벤트를 받는 화면은 새 `now`로 다시 호출할 수 있다. 이벤트 구독·연도 선택·임시 저장은 12단계의 책임이다.

## 검증

Node.js 24.13.1에서 다음 명령을 실행했다.

```powershell
node --test tests/fortune-periods.test.mjs
node --test tests/*.test.mjs
```

신규 테스트 9개, 기존 검사를 포함한 전체 **46개 통과, 실패 0개**.

| 검사 | 확인 내용 |
| --- | --- |
| 지원 전 연도 1901~2050 | 150개 연도의 12개월 구간 합집합, 누락·중복 없음, ID 유일성, 세운 포함 관계 |
| 기준 간지 | 2024년 갑자→을축→병인부터 병자까지 월주, 입춘 전 계묘/후 갑진 세운 |
| 외부 표본 | 기존 KASI 2024·2026 fixture의 월 경계 24건, 시각 차이 60초 이내 및 기준 시각 ±2분 현재 구간 전환 |
| 절입 경계 | 2024년 12절입의 정각·±1초·±60초 유예와 ±60.001초 확정, 기존 사주 계산의 월주와 연결 확인 |
| 출생 기간 | 출생 전 연도 거부·월 비활성·출생일 잘라내기·12월 31일·입력 객체 보존 |
| 부분 사주 | 시간 미상, 입춘일 연·월주 미확정, 일간 없음, 음력 윤달과 양력 등가 입력 |
| 십성 | 일간 10종에서 연간과 월간이 모두 출생 일간에 대한 십성인지 확인. 기존 십성 100조합 검사도 통과 |
| 날짜·상한 | 윤년 2월, 양력 월 시작, 2024년 대설 한국 날짜 이월, 2051 소한/입춘 내부 경계, 선택 연도 끝 제외 |
| 검증·재현성 | 빈 입력, 잘못된 연도·시각·날짜, 반복 호출 간 객체 독립성 |

전 연도 구간 검사는 생성·연속성 검증이다. 전 기간 모든 절입 시각의 독립 정확성 검증이나 해석 콘텐츠 검증은 아니다. 외부 자료 비교는 기존 [KASI 표본](./SAJU_VALIDATION.md)을 재사용했으며 신규 역사 자료를 확보한 검증으로 세지 않는다. 11~13단계 콘텐츠·화면·종합 검수는 미완료다.
