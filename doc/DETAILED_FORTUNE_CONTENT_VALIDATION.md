# 분야별 상세·월운 콘텐츠 구현 및 검수

완료일: 2026-10-16. 상세 콘텐츠 버전: 1.0.0. 실행순서 **11단계 완료** 기록이다. 화면 연결은 12단계에서 진행하며 이 문서만으로 13단계 종합 검수 완료를 뜻하지 않는다.

## 작성 범위

| 파일 | 내용 |
| --- | --- |
| `js/content/annual-details.js` | 십성 10종 × 총론·재물·직장/사업·가정/건강·이성/대인관계 5영역, 총 50개 상세 해석 |
| `js/content/monthly-details.js` | 월간 십성 10종의 요약·네 분야·주의점·실천 조언 70개 필드, 연간/월간 100조합의 명시적 연결 문구 |
| `js/fortune-interpreter.js` | 기간 계산 결과에 맞는 문구 선택, 근거·상태·콘텐츠 ID 반환 |
| `tests/fortune-interpreter.test.mjs` | 콘텐츠 완전성·100조합 선택·재현성·누락·오류·부분 사주·비변경성 검사 |

각 연간 영역은 요약 1문장, 상세 2문단(문단당 2문장), 기회·주의점·실천 조언을 갖는다. 가정/건강은 가족 소통과 생활·휴식을 각각 문단으로 작성했다. 월운은 실제 월간 십성에 맞는 간결한 문구를 사용하며 양력 월 이름만 바꾸어 운세를 만들어내지 않는다.

연간 주제 10종은 기존 `ANNUAL_READINGS` 제목과 일치시켰다. 원문 배열을 객체로 변환하는 코드는 ID와 필드 구조를 붙이는 역할이며, 100조합의 연결 문장은 각 조합별로 작성한 데이터다. 일반 문장 몇 개를 자동으로 이어 붙여 100개인 것처럼 세지 않는다.

## 선택·예외 계약

`interpretDetailedFortune(result, periods)`에 기존 사주 계산 결과와 `calculateFortunePeriods()` 반환값을 전달한다. DOM·시간 조회·저장·난수를 사용하지 않는 순수 선택 모듈이다. 선택된 일간과 기간 범위, 연간/월간 십성과 연결 관계가 맞지 않으면 오류를 반환한다.

- 기존 기간 구조는 그대로 보존하고 `version`, `annualReadings`, `monthlyReadings`, `contentIds`, `contentStatus`, `note`를 추가한다.
- 각 해석의 `basis`에는 출생 일간, 연간/월간 십성, 간지, 세운 연도, 실제 적용 시작·끝을 기록한다. 선택 문구에는 안정적인 ID와 `requires` 조건이 있다.
- 연간은 영역별 정확한 A 키, 월운은 정확한 M 키와 A/M 연결 키를 사용한다. 월운의 행동 방향은 M, 연간 A는 맥락을 설명한다. 날짜 해시·이름·접속 순서로 변형하지 않는다.
- `annualReadings[].areas`는 5영역 객체다. 월운은 `monthlyReadings[].segments[].reading`에 7개 필드, `bridge`에 연결 문구를 갖는다.
- 필수 연간 문구가 없거나 조건이 맞지 않으면 해당 영역을 `unavailable-content`, 연간 해석을 `partial-content`로 표시한다. 다른 영역은 유지한다.
- 월간 문구나 연결 문구가 빠지면 해당 구간 해석 전체를 `unavailable-content`로 반환한다. 기간과 계산 근거는 남기고 다른 십성의 문구로 대체하지 않는다. 안내는 ‘이 해석을 준비하지 못했어요.’다.
- `contentStatus`는 `complete` / `partial` / `unavailable`이며 계산의 `status`와 분리한다. 출생 전 월·계산 실패 월·일간 미확정은 각각 기존 상태를 유지하고 개인별 문구를 만들지 않는다.
- 월을 넘어 같은 절기 구간이 이어지면 `continuedFromPreviousMonth=true`로 표시한다. 같은 D/A/M은 같은 문구를 사용한다는 제한을 안내한다.
- 출생 시간이 없거나 출생 연·월주가 미확정이어도 확정된 D로 선택할 수 있다. 미확정 안내를 유지하며 연간·월간 해석에 제외된 기둥을 다시 사용하지 않는다.
- 선택적 세 번째 인자 `{ annual, monthly, bridges, version }`는 콘텐츠 편집 미리보기·누락 검증용이다. 결과는 복사하여 반환하므로 편집이나 렌더링이 원본 콘텐츠를 바꾸지 않는다.

## 수행한 검사

Node.js 24.13.1:

```powershell
node --test tests/fortune-interpreter.test.mjs
node --test tests/*.test.mjs
```

신규 **11개**, 기존 검사를 포함한 전체 **57개 통과, 실패 0개**.

- 연간 50개·월간 70개·연결 100개, 총 220개 ID와 조건·본문 누락 없음.
- 연간 본문 100문단과 연결 100문장은 각각 완전히 같은 문자열의 중복 없음. 문장 의미의 유사성이 없다는 보증은 아니다.
- 일간 10종의 실제 출생 사례와 2020~2029년 기간에서 연간/월간 100조합 모두 선택됨을 확인했다.
- 이름 변경·양음력 등가 입력·저장 복원·시간 미상에서 선택 문구 재현성 확인.
- 출생 전 기간, 입춘 전후 세운 변경, 같은 절기 월의 다음 양력 월 연결, ±60초 현재 강조 유예 보존 확인.
- 문구 삭제·잘못된 `requires` 조건·월 계산 실패를 주입하여 미제공 상태가 정상 운세로 대체되지 않는지 확인.
- 입력과 콘텐츠 객체 비변경성, 잘못 연결한 기간/십성 거부, 특정 확정적 사건 약속·중대한 결정 지시 문구의 문자열 검사 통과.

## 편집 검수

작성한 문구에서 분야별 내용, 연간 주제와 월간 행동의 연결, 단정 표현과 반복을 검토했다. 정인의 가정/건강 주의 문구에서 겹친 부정을 ‘도움을 받았더라도 자신의 필요를 말할 여지를 남겨두세요.’로 고쳤다.

실제 모듈 출력 3건의 총론·네 분야·월운을 별도로 읽었고 [대표 출력](./DETAILED_FORTUNE_SAMPLES.md)에 보관했다.

| 조합 | 확인한 연결 |
| --- | --- |
| 연간 정재 / 월간 편재 | 예산·일정의 유지 범위를 먼저 정하고 새 제안의 부담을 비교. 관리와 새 기회 탐색을 상반된 지시로 제시하지 않음 |
| 연간 편관 / 월간 정인 | 도전의 책임을 혼자 떠안지 않고 참고 자료·지원 질문을 준비. 과도한 압박이나 어려움 예고 없음 |
| 연간 상관 / 월간 정관 | 변경 이유를 완료 기준으로 설명하고 바꾸지 않을 약속을 확인. 무조건 바꾸라는 말과 무조건 따르라는 말을 결합하지 않음 |

건강은 생활 관리, 재물은 예산·자원 관리 관점으로 작성했다. 직업·혼인 상태·성별을 임의로 가정하지 않는다. 같은 주제의 반복과 ‘살펴보세요’ 중심의 문체는 남아 있으며 무제한 개인화된 전문 사주 풀이로 소개하지 않는다.

자동 문자열 검사나 대표 출력 검수는 의미상의 모든 모순을 증명하거나 전문가 감수를 대신하지 않는다. 기존 사이트의 화면·HTML은 이번 단계에서 바꾸지 않았다. 12단계에서 화면에 연결한 후 실제 가독성·접근성·입력 갱신을, 13단계에서 종합 검증을 수행한다.
