# 1차 검수와 콘텐츠 보강

검수일: 2026-10-15. 대상은 오늘의 운세·사주팔자·내 성향의 초기 구현이다. 평생운세·게시 작업은 범위에 포함하지 않았다.

## 발견 사항과 수정

| 발견 사항 | 수정 |
| --- | --- |
| 공백 없는 긴 영문 이름이 모바일 출생 정보 카드 밖으로 잘림 | profile-copy에 최소 너비와 단어 줄바꿈 처리. 20자 영문 이름으로 다시 확인 |
| 연도에 윤달이 없어 체크할 수 없는 이유가 불명확함 | 선택 연도의 윤달 유무·윤월과 다음 선택 방법을 도움말에 표시 |
| 관련 없는 입력이나 1분 갱신 때도 날짜 선택지를 재생성함 | 옵션 목록이 바뀌지 않으면 기존 option 노드를 유지해 선택 상태와 키보드 사용을 안정화 |
| 오류를 수정해도 이전 오류 문구가 남음 | 입력 변경 시 이전 오류 문구 정리 |
| 주제가 8일 후 돌아올 때 흐름·분야별 조언까지 동일함 | 주제마다 설명 2종을 추가해 기본 포함 24종으로 확대. 같은 주제의 설명·실천 팁을 함께 순환 |
| 오행 구성에서 없는 요소 이름 뒤의 조사 연결이 어색함 | 목록형 문장으로 바꾸고 결핍을 의미하지 않는다는 설명 유지 |

콘텐츠 버전은 1.1.0으로 올렸다. 주제 키워드·제목·주의점은 여전히 8개 주제를 순환하고, 상세 설명과 실천 팁은 24개 묶음으로 순환한다. 반복이 완전히 사라졌다고 표현하지 않는다.

## 실제 브라우저 검수

개인 프로필과 분리한 숨김 Chrome과 로컬 서버로 확인했다. 자동 검사 후 저장한 스크린샷을 직접 확인했다.

- 입력 전 결과 없음, 빈 입력 오류, 오류 수정 후 안내 정리
- 윤년·평년의 2월 선택지, 선택지 노드 유지, 2022년 윤달 비활성화 설명
- 생년월일 입력, 이름 문자열 안전 표시, 정보 수정과 재조회
- 세 메뉴 이동과 저장 복원, 손상된 저장 데이터 처리
- 절입 시각 인접 입력의 부분 결과 안내, 실제 윤달 입력과 환산 날짜
- 시간 미상 시주 제외와 오행 6글자 집계
- 같은 입력 새로고침의 주제 일관성, 날짜 변경 후 주제 갱신
- 저장 차단 시 현재 페이지 계산 유지와 임시 보관 불가 안내
- Escape로 입력 창 닫기
- 세 페이지 320·360·768·1280px의 페이지·입력창 너비와 긴 이름 텍스트 경계

검사 명령(Windows Chrome·Python·Node 22 환경):

```powershell
python tests/run-browser.py
```

8765·9225 포트가 사용 중이면 기존 서버나 브라우저를 재사용하지 않고 중단한다. 사용한 임시 프로필과 테스트 프로세스만 정리한다. 별도 서버·CDP 환경에서는 browser-smoke.mjs에 LUCK_QA_BASE·LUCK_QA_CDP를 지정할 수 있다.

## 남은 제한사항

- 과거 전체 절기 시각의 독립 대조와 전문가 감수는 이번 검수로 완료되지 않는다. 사주 계산은 고정 UTC+9·자정 경계 정책이고 과거 표준시·서머타임·태양시 보정은 없다.
- 성향은 일간 기반 자기 성찰 콘텐츠이며, 오늘의 운세는 날짜별 생활 제안이다. 전문가 사주 풀이·과학적 성격 진단·확정적 미래 예측으로 제시하지 않는다.
- 브라우저 검수는 데스크톱 Chrome의 반응형 에뮬레이션이다. 실제 iOS Safari·Android 기기·스크린리더 전체 검수는 수행하지 않았다.
- 무료 웹폰트는 CDN에서 로드한다. 네트워크가 없으면 시스템 폰트로 대체된다.
- GitHub Pages 실제 게시와 게시 URL 검증은 이번 작업에 포함하지 않았다.

7단계의 초기 검수·보강은 완료했다. 다음 계획은 8단계 평생운세의 제공 범위 결정이며, 자동으로 구현을 시작하지 않는다.
