# 해석 콘텐츠와 선택 규칙

콘텐츠 버전: 1.1.0. 외부 운세 API·AI 호출 없이 저장된 한국어 문구와 명시적인 규칙을 사용한다.

## 파일과 역할

- `js/content/interpretations.js`: 일간 10종, 오행 5종, 용어 설명, 오늘의 주제 8종과 실천 팁 24종
- `js/content/daily-details.js`: 주제당 추가 설명 2종. 기본 설명과 합쳐 24종의 흐름·관계·일·생활 문구를 제공한다.
- `js/interpreter.js`: 계산 결과와 콘텐츠를 연결하는 순수 함수
- `js/saju-calculator.js`: 사주 계산과 날짜별 일진. 콘텐츠 선택과 분리한다.
- 각 페이지 스크립트: 공통 결과를 구독하고 textContent 기반으로 표시한다.

## 사주팔자와 내 성향

1. 확정된 일주의 천간으로 일간 10종의 설명을 선택한다.
2. 각 일간에는 비유·대표 성향·태그 3개와 행동 방식·강점·관계·스트레스·균형 팁 5개를 준비했다.
3. 사주팔자는 개인별 일간 설명과 실제 오행 구성 설명, 공통 용어 설명 4개를 제공한다.
4. 오행 분포는 확정된 기둥의 천간·지지 글자 수만 집계한다. 강약·격국·용신·신강신약을 계산하지 않으며, 특정 요소의 부재를 성격 결핍으로 연결하지 않는다.
5. 시간 미상·절입 경계로 제외한 기둥은 집계에 넣지 않고 부분 결과임을 안내한다. 일간 설명은 확정된 일주를 사용하므로 그대로 제공할 수 있다.
6. 성향은 일간의 전통적 이미지를 빌린 자기 성찰용 편집 콘텐츠이며 과학적인 성격 진단으로 제시하지 않는다.

## 오늘의 운세

서비스의 오늘의 운세는 **날짜·출생 정보로 선택하는 생활 제안**이다. 객관적인 길흉 점수나 사건 발생 확률을 계산한 결과가 아니다. 이름, 재산, 건강 상태 등을 추측하지 않는다.

1. 한국 날짜 키(YYYY-MM-DD)로 오늘의 일진을 계산해 표시한다.
2. 한국 음력 변환 후의 양력 출생일과 확정된 일주를 선택 기준으로 사용한다. 이름·윤달 표기 형식·미확정 기둥·출생 시간은 주제 선택을 바꾸지 않는다.
3. 양력 출생일과 일주의 문자열에 FNV-1a 방식의 안정적인 해시를 적용한다. 날짜의 일련번호와 합해 8개 주제 중 하나를 선택한다.
4. 주제는 작은 시작·열린 대화·가벼운 정리·편안한 회복·새로운 시선·작은 마무리·나만의 속도·작은 인정이다.
5. 흐름, 관계, 일·공부, 생활, 주의점을 전부 같은 주제 묶음에서 선택한다. 서로 다른 주제의 ‘새 일을 늘리기’와 ‘일정을 덜기’ 같은 지시를 임의 조합하지 않는다.
6. 실천 팁과 세부 설명은 선택된 주제 안의 3종 중 날짜 구간과 같은 해시로 함께 결정한다. 8일 연속 같은 주제를 반복하지 않으며 같은 주제가 돌아와도 다음 세부 설명·실천 팁을 제공한다.
7. 콘텐츠 양은 유한하다. 주제 키워드·제목·주의점은 8일 후 돌아올 수 있고, 세부 설명·실천 팁은 24일 주기로 반복될 수 있다. 무제한 개인별 풀이로 표현하지 않는다.

## 우선순위와 예외 처리

1. **입력 없음:** 개인별 결과를 만들어내지 않고 입력 대기 상태를 표시한다. 실천 체크를 비활성화하고 가짜 오행 숫자를 표시하지 않는다.
2. **입력 오류:** 기존 계산 검증에서 거부하며 정상 해석으로 취급하지 않는다.
3. **계산의 불확실성:** 확정된 일주만 성향·주제 선택에 사용하고, 구성 설명에서 제외한 기둥과 범위를 먼저 밝힌다.
4. **주제 일관성:** 주제 묶음이 분야별 문구·주의점·실천 팁보다 우선한다. 실천 팁은 해당 주제 내부에서만 고른다.
5. **표시용 이름:** 제목에만 쓰며 해석의 길흉이나 주제를 바꾸지 않는다.
6. **지원 날짜 밖:** 무관한 기본 운세를 대신 표시하지 않고 날짜 범위를 안내한다.

## 일관성·갱신·체크 상태

- 같은 콘텐츠 버전·양력 출생일·일주·조회 날짜에는 같은 결과를 반환한다. 난수나 접속 순서를 사용하지 않는다.
- 같은 출생일을 양력·음력으로 다르게 입력해도 환산 결과가 같으면 같은 주제를 제공한다.
- 공통 날짜 감시가 한국 날짜 키 변경을 확인하면 `luck:date-change`를 발행한다. 1분 간격과 탭 복귀 때 확인하고 오늘의 콘텐츠와 적용 날짜를 함께 갱신한다.
- 실천 체크는 해당 페이지의 현재 입력·날짜·행동에만 적용한다. 입력이나 날짜·팁이 달라지면 초기화하며 페이지를 이동하거나 새로고침해도 초기화된다.
- 콘텐츠 버전이나 문구를 편집하면 향후 표시 내용이 달라질 수 있다. 기존 사용자 입력만 임시 저장하며 해석을 영구 저장하지 않는다.

## 문구 검수와 검증

- 모든 일간에 다섯 영역의 설명이 있고, 모든 주제에 네 분야의 힌트(주의점 포함)와 세 실천 팁이 있는지 확인한다.
- 비슷한 문구를 다른 영역에 그대로 반복하지 않도록 영역별로 작성했다. 문구는 단정 대신 돌아보기·확인하기·선택하기 중심으로 편집했다.
- 투자·대출·복권·진단·치료·확정적 미래 예측이나 공포를 유발하는 지시를 넣지 않았다. 이는 콘텐츠 작성 기준이며 전문가 감수를 완료했다는 뜻은 아니다.
- `tests/interpreter.test.mjs`: 60개 일주에서 일간 10종의 누락 확인, 날짜별 96일 선택 범위와 실천 24종, 같은 입력의 재현성, 이름·양음력 표현의 독립성, 부분 결과, 자정·연도 경계, 빈 입력, 날짜 오류를 검증한다.
- 기존 사주·달력 테스트는 계속 유지한다. 통합 결과는 IMPLEMENTATION_PLAN.md에 실제 확인한 범위만 기록한다.

## 분야별 상세·월운 선택 규칙 설계 (2026-10-16)

9단계에서 확정한 기준을 11단계에서 별도 상세 콘텐츠 버전 1.0.0으로 구현했다. 기존 오늘의 운세 콘텐츠 1.1.0은 유지하며 실제 페이지 연결은 12단계에서 완료했다. 전체 조건·데이터 구조는 [상세 설계](./DETAILED_FORTUNE_SPEC.md), 구현 반환 상태·검증 결과는 [콘텐츠 검수 기록](./DETAILED_FORTUNE_CONTENT_VALIDATION.md)을 따른다.

| 영역 | 선택값 | 문구 구성 |
| --- | --- | --- |
| 기본 성향 | 확정된 일간과 그 오행 | 기존 성향·인생 경향, 연도와 무관 |
| 연간 총론·재물·직장/사업·가정/건강·이성/대인관계 | 일간 대비 연도 천간 십성 A | A별 총론 및 네 분야, 요약·상세 문단·기회·주의점·실천 조언 |
| 월운 | 일간 대비 월간 십성 M과 해당 구간의 A | M별 요약·네 분야·주의점·실천 조언 + A/M 연결 문구 |

- 기존 연간 십성 10종의 주제를 유지한다. 연간 상세 10종×5영역, 월간 10종, 연간/월간 연결 100조합을 별도 콘텐츠로 작성한다.
- 월운 행동 방향은 M, 연간 맥락은 A가 담당한다. 한 양력 월의 절입 전후에 다른 M이 적용될 수 있고 입춘에서는 A도 바뀐다.
- 입력과 기간을 검증한 뒤 정확한 키 하나를 선택한다. 이름·달력 표기·난수·날짜 해시를 사용하지 않는다. 같은 일간·기간의 해석이 같은 것은 의도된 제한이다.
- 문구에 안정적인 ID·필요 계산값·버전을 두고 반환값에 선택 근거를 기록한다. 키가 누락되면 개발 검사는 실패시키며 화면은 해당 영역 미제공 상태로 처리한다. 다른 십성 문구로 대체하지 않는다.
- 원국 전체의 지지 관계·지장간·용신·신강약·대운은 계산하거나 추정하지 않는다. 길흉 점수·사건 발생 확률도 만들지 않는다.
- 가정/건강은 소통과 생활 관리, 재물은 자원 관리 관점으로 작성한다. 연애·직장 상황을 가정하거나 재산·승진·임신·질병을 확정하지 않는다.
- 11단계에서 실제 문구 작성·대표 출력 검수와 선택 규칙·완전성 테스트를 수행했다. 신규 11개·전체 57개 검사 통과. 13단계 종합 검수와 전문 감수 완료를 뜻하지 않는다.

후속 13단계 검수 완료(2026-10-16): 전체 테스트 63개와 Chrome 검사를 통과하고 대표 출력 3건·연결문구 100개를 다시 읽었다. 자동 검사는 계산 근거·행동 유형의 불일치, 누락·정확히 같은 문구 중복·금지 표현을 확인하며 의미상 상충 전체를 자동 판정하지 않는다. 동일 A/M의 반복은 의도된 제한이다. [종합 검증 보고서](./DETAILED_FORTUNE_FINAL_REVIEW.md)를 참고한다. 전문 감수와 사건 예측 타당성 검증은 별개다.

## 원국 상세의 확정 설계 (2026-10-19)

14단계 [원국 상세 설계](./NATAL_DETAIL_SPEC.md)를 확정했다. 실제 원고·선택 모듈은 16단계에서 구현한다. 기존 일간 성향·연간 상세·월운의 문구와 버전은 별도로 유지한다.

- D(일간) 10종·P(일주) 60종의 설명, 각 기둥의 십성·지장간, 계절 배경과 원국 요약/성향/일·자원/관계/생활 균형 5영역을 제공 대상으로 정했다.
- 분야는 D별 기본 문구와 C별 맥락으로 조합한다. C는 확정 월간의 십성을 우선하고 월주가 미확정이면 일지 본기의 십성을 사용한다. 우세 십성·강약 판정이 아닌 편집 순서이며 선택 이유를 표시한다.
- 기본 문구만 실천 행동을 정하고 맥락·계절은 조건과 질문을 보완한다. 일간·일주·맥락·계절의 필수 특징과 정확한 키를 확인하고 ID 중복을 제거한다. 기본 누락은 영역 미제공, 보조 누락은 해당 보조 문구 미제공으로 처리한다.
- 같은 원국·콘텐츠 버전은 이름·날짜·선택 연도·양음력 표기와 무관하게 같은 결과다. 같은 특징의 반복을 허용하며 일주 하나로 원국 전체를 평가하거나 근거 없는 차이를 만들지 않는다.
- 원국 상세의 ID·버전·조건·근거를 독립 관리한다. 미확정 월주의 계절·지장간을 만들지 않고, 시간 미상에서는 시주 파생 설명을 제외한다. 사건 예측·체질 진단·전문 용신 해석으로 표현하지 않는다.

15단계 특징 입력 구현 완료: `calculateNatalFeatures()`의 `dayMaster`·`dayPillar`·기둥별 `stemRelation`/`hiddenStems`·`season`·`context`·`availability`를 16단계 해석 선택의 입력으로 사용한다. `unavailable-feature`는 계산 특징 미확정이며 콘텐츠 누락과 구별한다. `surfaceElements`와 지장간은 합산하지 않는다. [구현 계약](./NATAL_FEATURES_VALIDATION.md)을 참고한다. 이번 단계는 원고·해석 선택 구현 완료를 뜻하지 않는다.

16단계 완료(2026-10-19): 원국 상세 카탈로그 196개 ID와 `interpretNatalDetails(features, catalog?)`를 구현했다. 일간 10개는 기존 원고를 sourceRefs/sourceVersion으로 추적해 재사용하고, 일주 60개·기본 분야 50개·맥락 50개·십성 10개·계절 4개·월지 12개를 작성했다. 이름·날짜·달력·난수로 변형하지 않는다.

선택 우선순위는 정확한 D/P 조건의 기본 문구 → C 조건의 보조 문구다. 보조는 action이 null인 원고만 허용하며 계절 설명은 전체에서 한 번 출력한다. 같은 십성은 실제 등장한 위치를 모두 근거에 모아 1회 설명한다. 기본 누락은 해당 영역 미제공, 보조 누락은 기본을 유지하는 부분 제공으로 처리한다. 신규 13개·전체 88개 검사와 대표 출력 4건 검수를 수행했다. [구현·검수 기록](./NATAL_CONTENT_VALIDATION.md)을 참고한다. 화면 연결과 종합 검증은 17~18단계다.

17단계 화면 연결 완료: 개인별 상세를 먼저 배치하고 공통 용어 4개는 별도 펼치기로 구분했다. 실제 간지·십성·지장간의 위치와 편집 문구를 구분하고, 설명별 실제 비교 천간과 선택 이유를 근거 펼치기에 표시한다. 누락·부분 사주 상태도 그대로 전달하며 내부 ID는 본문에 나열하지 않는다. [화면 검수 기록](./NATAL_UI_VALIDATION.md)을 참고한다. 18단계 종합 검증도 완료했다. [최종 보고서](./NATAL_FINAL_REVIEW.md)를 참고한다.
