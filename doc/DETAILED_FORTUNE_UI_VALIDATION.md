# 상세 운세·월운 화면 연결 검수

2026-10-16, 실행순서 12단계. 계산·콘텐츠는 10~11단계 모듈을 사용한다.

## 구현

- 평생운세의 기존 인생 경향·최대 5개 세운 요약을 유지하고 `#annual-detail`에 조회 연도, 적용 세운, 5개 분야, 12개월 월운을 연결했다. 사주팔자 링크와 기존 세운 요약의 상세 보기로 진입한다.
- `js/fortune-view.js`가 DOM·입력 구독·시계 이벤트·임시 저장을 담당하고 `js/fortune-view-state.js`가 선택 유효성·기본 선택·고정 UTC+9 기간 표시를 담당한다.
- 연도는 양력 환산 출생 연도와 1901 중 큰 값부터 2050까지다. 입춘 전후 세운은 각각의 실제 적용 기간을 표시한 선택 버튼으로 구분한다. 출생 이전 구간은 제외한다.
- 월운은 1~12월을 모두 표시하고 선택 월의 절입 전후 구간을 각각 출력한다. 출생 전 월은 안내만 표시한다. 연간 선택을 바꿔도 월운의 실제 세운 연결은 바뀌지 않는다.
- 총론·재물·직장/사업·가정/건강·이성/대인관계 순서로 요약, 본문, 기회, 주의, 실천을 보여준다. 일간·세운/월주·십성은 ‘해석 기준 보기’로 확인한다.
- 네이티브 select·button·details와 `aria-pressed`를 사용한다. 월 버튼은 Tab으로 이동하고 Enter/Space로 선택한다. 시계 갱신 때 선택 버튼 포커스를 보존한다.
- `luck.fortuneView.v1`에는 `{year, cycleYear, month}`만 저장한다. 유효한 수동/복원 선택은 시계가 덮어쓰지 않으며, 자동 선택은 연도·월·입춘을 따라간다. 잘못된 저장값은 기본값으로 복구하고 저장 차단 시 메모리에서 동작한다.
- 미입력, 부분 사주, 출생 전 월, 현재 연도 범위 밖, 계산 실패를 구분한다. 입춘 ±60초 자동 선택은 세운 하나를 확정하지 않고 직접 선택을 허용한다. 현재 월운도 절입 ±60초에는 후보만 표시한다.

## 실행 및 결과

```powershell
node --test tests/*.test.mjs
node tests/run-browser.mjs
```

- Node 24.13.1: 전체 모듈 검사 60개 통과(기존 57개 + 선택 상태 검사 3개).
- 기존 `tests/browser-smoke.mjs` 통과: 네 메뉴, 공통 입력/음력 윤달/시간 미상, 이름 안전 출력, 복원, 날짜 갱신, 입력 대화상자와 반응형 회귀.
- 신규 `tests/fortune-browser.mjs` 통과: 상세 진입, 5개 분야·12개월, 연도/세운/월 변경, 월운과 연간 선택의 독립성, 새로고침·메뉴 복귀 복원, 키보드 Enter 및 포커스, 출생 연도 잘라내기, 2050 상한, 입력 수정, 부분 사주, 자동/수동 시계 갱신, 입춘 경계, 범위 밖 현재 연도, 저장 차단, 계산 실패.
- 320·360·768·1280px에서 가로 넘침 검사. 320px와 1280px 상세/월운 캡처를 열어 문장 줄바꿈·선택 표시·기간 안내를 확인했다.
- `git diff --check` 통과.

`tests/run-browser.mjs`는 별도 패키지 없이 Windows Chrome과 Node 22 이상을 사용한다. 루프백 임시 포트 서버, 전용 임시 Chrome 프로필로 기존 서버/사용자 프로필과 분리하고 종료 후 정리한다. Chrome 경로는 `LUCK_CHROME`으로 변경할 수 있다. `LUCK_QA_SCREENSHOTS`를 지정하면 화면 캡처를 저장한다. Python 실행기가 없는 환경에서도 검수 가능하다.

## 한계와 후속 범위

이번 검수는 12단계 화면 연결의 수용 확인이다. 13단계의 독립 절입 자료 대조·종합 검증 체크를 대신하지 않는다. 실제 모바일 기기 전체 검수, 전문 해석 감수 및 배포는 수행하지 않았다. 운세 문구의 예측 타당성을 검증한 것이 아니다.
