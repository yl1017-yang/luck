# 오늘의 결

사이트: [https://yl1017-yang.github.io/luck/](https://yl1017-yang.github.io/luck/)

HTML·CSS·바닐라 JavaScript로 만든 운세 대시보드입니다. 

## 현재 구현 범위

- 오늘의 운세·사주팔자·내 성향·평생운세 메뉴 전환
- 생년월일, 양력·음력, 윤달, 출생 시간·시간 모름 입력
- 이름 또는 별명 선택 입력(최대 20자), 메뉴별 결과 제목에 반영 및 같은 탭에서 복원
- 입력 정보 수정, 올해 흐름과 성향·평생운세 요약, 한국 시간 기준 날짜 표시
- 모바일 대응과 키보드 접근 가능한 입력 대화상자

**네 메뉴를 실제 입력과 저장된 해석 콘텐츠에 연결했습니다.** 사주팔자는 네 기둥·일간/일주·십성/지장간·계절/오행 및 분야별 원국 상세와 계산 근거를, 내 성향은 일간·일주·월간과 일지 본기의 관계를 연결해 기질·일·관계·스트레스·회복·돈과 선택의 6개 영역을 상세히 설명합니다. 평생운세는 총운과 초년·중년·말년 및 분야별 개인 풀이, 현재 세운부터 2개 연도의 문장형 풀이, 선택 연도의 12개월 월운을 제공합니다. 오늘의 운세는 날짜와 출생 정보로 생활 조언을 선택하며 실제 사건의 길흉을 예측하지 않습니다. 입력 전에는 개인별 결과를 표시하지 않습니다. 양력·음력 변환은 korean-lunar-calendar 0.4.0, 사주 계산은 lunar-javascript 1.7.7에 한국 시간·자정 기준을 보정해 사용합니다. 시간 미상과 절입 경계의 불확실한 기둥은 제외합니다. 출생 정보는 서버로 전송하지 않고 sessionStorage에 임시 보관하며, 같은 탭에서 이동·새로고침하면 다시 계산합니다. 실천 체크는 현재 페이지의 입력·날짜·행동에만 적용됩니다.

사주팔자 상세 확장의 **14~18단계 설계·계산·콘텐츠·화면·종합 검증**을 완료했습니다. 전체 94개 검사와 Chrome 3개 스크립트가 통과했습니다. 지장간 12지지·28항목 구성 일치와 나열 순서 차이 5건을 기록했습니다. [최종 검증 보고서](./doc/NATAL_FINAL_REVIEW.md)에 출처·대표 출력·검증 범위와 한계를 정리했습니다. 전문 감수·예측 타당성·배포 완료를 뜻하지 않습니다. [설계 문서](./doc/NATAL_DETAIL_SPEC.md)의 범위를 따릅니다.

평생운세 상단은 원국 기반 총평, 초년·중년·말년의 관점과 성향·직업/재물·관계·생활 균형을 상세 문단으로 제공합니다. 각 설명의 간지·십성 근거를 펼쳐볼 수 있습니다. 나이별 대운 계산은 포함하지 않으며 시간 미상일 때 말년 풀이를 임의 생성하지 않습니다. [풀이 기준](./doc/LIFETIME_GUIDE.md)을 참고하세요.

평생운세는 상단 개인 풀이와 연도별 요약, 연도 선택 후 12개월 월운으로 구성합니다. 중간에 반복되던 연간 분야별 상세 카드는 제거했습니다.

평생운세 상세 풀이를 총운 4문단, 초년·중년·말년 각각 4~5문단, 성격·직업·재물·관계·생활 균형 각각 3~4문단으로 확장했습니다. 미확정 기둥의 시기별 풀이는 생성하지 않습니다.

월별 운세는 항목별 조언 대신 이 시기의 성향·업무 방식·지출·관계를 연결한 7개 문단으로 제공합니다. 절기별 적용 기간을 구분하며 계산 근거와 해석 안내는 펼쳐볼 수 있습니다.

사주팔자 상세풀이는 펼치기 클릭 없이 바로 표시합니다. 일간·일주에 따른 기질과 강점, 스트레스, 맞는 업무와 돈 관리, 애정·대인관계·생활을 직접 설명하며 계산 근거와 기초 용어는 별도로 펼쳐볼 수 있습니다.

내 성향은 현재의 사고·행동·관계 방식을 설명하고, 평생운세는 인생 주선과 초년·중년·말년, 경력·재물·가정의 장기적인 전개를 독립된 원고로 제공합니다. 두 메뉴의 총평·제목·본문을 분리했습니다.
