# 오늘의 결

사이트: [https://yl1017-yang.github.io/luck/](https://yl1017-yang.github.io/luck/)

HTML·CSS·바닐라 JavaScript로 만든 운세 대시보드입니다. 

## 현재 구현 범위

- 오늘의 운세·사주팔자·내 성향·평생운세 메뉴 전환
- 생년월일, 양력·음력, 윤달, 출생 시간·시간 모름 입력
- 이름 또는 별명 선택 입력(최대 20자), 메뉴별 결과 제목에 반영 및 같은 탭에서 복원
- 입력 정보 수정, 오늘의 실천 체크, 한국 시간 기준 날짜 표시
- 모바일 대응과 키보드 접근 가능한 입력 대화상자

**네 메뉴를 실제 입력과 저장된 해석 콘텐츠에 연결했습니다.** 사주팔자는 네 기둥·일간/일주·십성/지장간·계절/오행 및 분야별 원국 상세와 계산 근거를, 내 성향은 일간 10종별 다섯 영역의 설명을 제공합니다. 평생운세는 인생 전반의 여섯 영역과 최대 5개 연도의 세운, 선택 연도의 분야별 상세와 12개월 월운을 제공합니다. 오늘의 운세는 날짜와 출생 정보로 생활 조언을 선택하며 실제 사건의 길흉을 예측하지 않습니다. 입력 전에는 개인별 결과를 표시하지 않습니다. 양력·음력 변환은 korean-lunar-calendar 0.4.0, 사주 계산은 lunar-javascript 1.7.7에 한국 시간·자정 기준을 보정해 사용합니다. 시간 미상과 절입 경계의 불확실한 기둥은 제외합니다. 출생 정보는 서버로 전송하지 않고 sessionStorage에 임시 보관하며, 같은 탭에서 이동·새로고침하면 다시 계산합니다. 실천 체크는 현재 페이지의 입력·날짜·행동에만 적용됩니다.

사주팔자 상세 확장의 **14~18단계 설계·계산·콘텐츠·화면·종합 검증**을 완료했습니다. 전체 94개 검사와 Chrome 3개 스크립트가 통과했습니다. 지장간 12지지·28항목 구성 일치와 나열 순서 차이 5건을 기록했습니다. [최종 검증 보고서](./doc/NATAL_FINAL_REVIEW.md)에 출처·대표 출력·검증 범위와 한계를 정리했습니다. 전문 감수·예측 타당성·배포 완료를 뜻하지 않습니다. [설계 문서](./doc/NATAL_DETAIL_SPEC.md)의 범위를 따릅니다.
